ABOUT THE PROJECT

About Urban Mobility Explorer

Project Purpose

Urban Mobility Explorer uses NYC taxi trip data to explore how taxi activity, speed, distance and fares change across different times and locations.

The Dataset

The project uses January 2019 NYC Yellow Taxi records containing information about locations, times, distances, fares and recorded speeds.

Technologies

HTML · CSS · JavaScript · Leaflet · Chart.js · Node.js · PostgreSQL

Key Limitation

Recorded taxi speed is an indicator of movement rather than a direct measurement of street congestion
