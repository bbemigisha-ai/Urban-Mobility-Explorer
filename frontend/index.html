ABOUT THE PROJECT

Understanding our cause,NYC Explorer

Our Purpose

Urban Mobility Explorer is an interactive data visualization project designed to make NYC taxi movement easier to understand. Instead of presenting millions of taxi records as raw data, the platform transforms them into maps, indicators, rankings and visual patterns that can be explored by time and location.

The Problem We Explore

New York City is constantly moving, but mobility patterns are not the same throughout the city or across the day. Taxi demand, recorded speed, trip distance and fares can vary significantly between locations and time periods. Our project helps users explore these differences and understand where and when taxi activity is concentrated.

The Dataset

The project uses January 2019 NYC Yellow Taxi trip records. The dataset contains information about pickup locations, pickup times, trip distances, fares and recorded trip speeds. The data was cleaned and processed before being stored and made available through the project's backend API.

How It Works

Processed taxi data is stored in a PostgreSQL database and accessed through a Node.js and Express API. The frontend uses JavaScript to request the data and dynamically update the dashboard. Leaflet powers the interactive NYC zone map while Chart.js creates the analytical charts.

What You Can Explore

Users can filter taxi activity by pickup hour and borough, search for individual taxi zones, change the map metric, compare the busiest and least busy zones, and explore hourly patterns. Selecting a zone on the map provides a more detailed view of its taxi activity.

Technologies

HTML, CSS and JavaScript power the frontend experience. Leaflet provides the interactive geographic visualization, Chart.js supports the analytical charts, Node.js and Express provide the backend service, and PostgreSQL stores the processed relational data.

Our Approach

We designed the dashboard around three questions: where taxi activity is concentrated, how mobility changes throughout the day, and how movement characteristics differ across locations. The visualizations were selected to make these patterns easier to compare rather than simply displaying large amounts of data.

Important Limitation

Recorded taxi speed should be interpreted as an indicator of movement rather than a direct measurement of road congestion. The dataset does not provide stable vehicle identifiers or complete route information, so the project cannot reliably measure empty travel between passengers or reconstruct exact vehicle routes.
